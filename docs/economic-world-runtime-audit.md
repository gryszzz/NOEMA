## Safe implementation order

1. Verify the merged snapshot-streaming release is running and measure console
   memory, worker snapshot success, sampler cadence, Polymarket stream persistence
   and authenticated account history across multiple process cycles.
2. Build a typed, chain-ID keyed read-only registry and route current EVM wallet
   observations through it. Verify RPC chain identity and block freshness. Keep
   existing five-network output compatible; do not add guessed endpoints or
   token addresses.
3. Add a canonical asset metadata registry and bounded pair candidate store,
   then schedule one existing read-only discovery/quote path with provider quotas.
4. Mature DEX observations into timestamp-safe labels and compare simple baselines
   using after-cost outcomes, including negative results.
5. Research licensed traditional-market and official Robinhood surfaces before
   choosing or configuring a provider.
6. Add missing specialists/providers only after each feed's provenance, budget,
   coverage and failure behavior can be measured.
7. Keep promotion evidence separate from owner execution authority; do not
   enable a signer as a side effect of research work.
