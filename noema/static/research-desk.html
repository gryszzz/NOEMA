NOEMA WEB APP

Add NOEMA to your Mac

Use the hosted authenticated site as the app, so its live backend and login remain the source of truth.

  1. Open this site in Safari on macOS Sonoma 14 or later.
  2. Choose File → Add to Dock.
  3. Name it NOEMA and add it. Open NOEMA from the Dock and sign in there once; Safari keeps web-app site data separate.

The app needs a network connection for live state. It does not keep a service-worker copy of private account data offline.
