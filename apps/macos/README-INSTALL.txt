TEV — NOEMA trading room for macOS
==================================
1. Unzip TEV-mac.zip.
2. Drag TEV.app into /Applications (and into the Dock if you like).
3. First launch: right-click TEV > Open > Open (the app is unsigned, so macOS asks once).
4. Set your dashboard URL: right-click TEV > Show Package Contents > Contents/Resources/tev-url.txt
   (or write it to ~/.tev-url), e.g. https://<your-machine>.<your-tailnet>.ts.net/trading-room
5. Click TEV. It opens in its own window via Chrome/Brave/Edge (app mode) if installed, else Safari.
   Log in with the dashboard user/password you were given. The view is read-only.
Alt: in Safari open the dashboard, then File > Add to Dock — the TEV icon/manifest is built in.
